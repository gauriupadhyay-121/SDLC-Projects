# Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. The game allows users to play against the computer and displays the result of each round instantly.

## Features

* User vs Computer gameplay
* Random computer choice generation
* Instant win, lose, or draw result
* Score tracking
* Responsive and user-friendly interface
* Interactive design using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
4. Start playing Rock Paper Scissors!
